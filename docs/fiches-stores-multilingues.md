# Fiches des stores en cinq langues

Textes prêts à coller dans **App Store Connect** (Distribution > version > localisation à ajouter) et la **Play Console** (Présence sur le Store > fiche du Play Store principale > traductions). Les limites sont celles des stores : App Store, nom 30, sous-titre 30, texte promotionnel 170, mots-clés 100, description 4000 ; Google Play, titre 30, description courte 80, description complète 4000.

Points à vérifier avant de coller :

- Le nom reste **PuffyBird** dans toutes les langues. Ne jamais employer « Flappy » (nom, mots-clés, description).
- La description dit « Classement et succès en ligne » : à garder seulement une fois le classement et les succès créés (`docs/classement-en-ligne.md`). Les oiseaux payants (« en boutique ») : à garder seulement si les achats intégrés sont en place.
- Les captures d'écran peuvent rester les mêmes dans toutes les langues (le jeu est visuel). Pour de meilleurs résultats, refaire les captures dans chaque langue de téléphone (touche C dans Unity).
- Le jeu suit la langue du téléphone ; les langues absentes de la fiche tombent sur l'anglais.
