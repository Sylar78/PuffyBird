# Fiches des stores en cinq langues

Textes prêts à coller dans **App Store Connect** (Distribution > version > localisation à ajouter) et la **Play Console** (Présence sur le Store > fiche du Play Store principale > traductions). Les limites sont celles des stores : App Store, nom 30, sous-titre 30, texte promotionnel 170, mots-clés 100, description 4000 ; Google Play, titre 30, description courte 80, description complète 4000.

Fiches réécrites le 20/10/2026 après le refus App Store 4.3(a) (voir `docs/rejet-apple-4-3.md` dans les fichiers partagés) : nouveau nom **Elemental Phenix**, et la fiche part des phénix élémentaires, des neuf mondes et du mode Voyage des éléments.

Points à vérifier avant de coller :

- Le nom reste **Elemental Phenix** dans toutes les langues. Ne jamais employer « Flappy », ni « bird », « pipes », « tap to fly » ou « medal » (vocabulaire des clones) dans le nom, le sous-titre, les mots-clés ou le début de la description.
- « Classement et succès Game Center » : à garder seulement une fois le classement et les succès créés (`docs/classement-en-ligne.md`). La boutique : seulement si les achats intégrés sont en place.
- Captures : la première montre un phénix en armure dans un monde typé (Japon, néon, abysses), jamais un oiseau entre deux obstacles sur fond de prairie. Les captures peuvent rester les mêmes dans toutes les langues ; pour de meilleurs résultats, les refaire dans chaque langue de téléphone (touche C dans Unity).
- Le jeu suit la langue du téléphone ; les langues absentes de la fiche tombent sur l'anglais.
